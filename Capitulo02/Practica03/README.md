# Práctica 3. Diseñar prompts para redactar especificaciones técnicas, elaborar procedimientos, analizar requerimientos, generar reportes de ingeniería y documentar proyectos

**Duración de la práctica:** 30 minutos

## Descripción
Los participantes utilizarán **Google Gemini** para diseñar y aplicar prompts estructurados orientados a resolver tareas críticas en proyectos de ingeniería, tales como la elaboración de especificaciones técnicas, redacción de procedimientos normalizados, análisis de requerimientos, estructuración de reportes y documentación de proyectos, logrando resultados precisos y repetibles mediante la inteligencia artificial.

---

## Sección 1: Demostración del Instructor - Tres Pasos

1. **Autogeneración y contraste de un prompt básico frente a un prompt estructurado en Gemini:**
   * Abre tu sesión de Google Gemini y envía la siguiente instrucción para que el modelo demuestre el impacto de una estructura profesional:
     ```text
     Actúa como un Ingeniero Diseñador Senior.
     Primero, responde a esta petición genérica: "Haz un procedimiento para instalar una válvula de control".
     Segundo, responde a la misma petición utilizando un prompt estructurado que incluya rol específico, contexto operativo, restricciones técnicas de seguridad, formato de salida y audiencia objetivo.
     Compara ambos resultados para evidenciar la diferencia en precisión técnica.
     ```

2. **Aplicación de la técnica de Chain of Thought (Cadena de Pensamiento) para el análisis de requerimientos:**
   * Solicita al modelo procesar un problema técnico paso a paso utilizando el siguiente comando:
     ```text
     Actúa como un Ingeniero de Requerimientos Industriales.
     Diseña un prompt estructurado aplicando la técnica de Cadena de Pensamiento (Chain of Thought)
     para analizar los requerimientos de carga y fatiga de una estructura de soporte metálica,
     solicitando que el modelo desglose el razonamiento lógico antes de emitir la conclusión técnica.
     ```

3. **Generación automática de un reporte y documentación técnica normalizada en Gemini:**
   * Finaliza la demostración estructurando un informe formal con la siguiente instrucción:
     ```text
     Actúa como un Ingeniero Gestor de Documentación Técnica.
     Utilizando un prompt altamente estructurado, autogenera un reporte ejecutivo de inspección de equipos estáticos
     que incluya resumen de hallazgos, evaluación de criticidad y recomendaciones normativas bajo estándares internacionales.
     ```

---

## Sección 2: Práctica Guiada del Participante - Cinco Pasos

1. **Diseño de un prompt estructurado para la redacción de especificaciones técnicas en Gemini:**
   * Abre una nueva sesión en Google Gemini y envía la siguiente instrucción para crear especificaciones normalizadas de forma autónoma:
     ```text
     Actúa como un Ingeniero Especialista en Especificaciones de Materiales.
     Utilizando una estructura de prompt profesional (que defina Rol, Contexto, Tarea, Restricciones y Formato),
     genera las especificaciones técnicas completas para la adquisición de motores eléctricos de alta eficiencia
     destinados a ambientes corrosivos en una planta industrial.
     ```

2. **Creación de un procedimiento operativo estandarizado mediante instrucciones guiadas:**
   * Envía la siguiente instrucción para estructurar un protocolo operativo de seguridad:
     ```text
     Actúa como un Ingeniero de Seguridad y Procesos Operativos.
     Diseña un prompt estructurado para redactar el procedimiento de bloqueo, etiquetado y desenergización (LOTO)
     de un sistema de bandas transportadoras, asegurando que la salida incluya pasos secuenciales,
     advertencias de peligro y equipos de protección personal requeridos.
     ```

3. **Análisis estructurado de requerimientos técnicos complejos en Gemini:**
   * Solicita al asistente procesar un escenario de diseño industrial mediante el siguiente comando:
     ```text
     Actúa como un Ingeniero Arquitecto de Proyectos.
     Utiliza un prompt estructurado con la técnica de pocos ejemplos (Few-Shot) simulada
     para analizar los requerimientos de integración de un sistema de instrumentación y control en una línea de producción,
     identificando posibles cuellos de botella y dependencias críticas entre subsistemas.
     ```

4. **Generación de un reporte técnico de ingeniería estructurado para la dirección:**
   * Pide la elaboración de un informe gerencial utilizando la siguiente instrucción:
     ```text
     Actúa como un Ingeniero Director de Proyectos.
     Redacta un prompt estructurado que ordene a la IA generar un reporte técnico de avance de obra
     para la modernización de una subestación eléctrica, estructurado con métricas de rendimiento,
     desviaciones presupuestarias simuladas y plan de mitigación de riesgos.
     ```

5. **Consolidación y documentación de un proyecto de ingeniería mediante prompts repetibles:**
   * Finaliza la práctica creando una plantilla reutilizable de documentación técnica con el siguiente comando:
     ```text
     Actúa como un Ingeniero Gestor de Calidad y Estandarización.
     Diseña y presenta un formato de prompt maestro estandarizado que el equipo de ingeniería pueda reutilizar
     diariamente para redactar manuales, bitácoras y especificaciones técnicas con total consistencia en Google Gemini.
     ```

## Resultado esperado
Un dominio práctico en la construcción y aplicación de prompts estructurados, técnicas de cadena de pensamiento y plantillas profesionales en **Google Gemini**, optimizando la redacción de especificaciones, procedimientos, análisis y reportes dentro de los flujos de ingeniería.
