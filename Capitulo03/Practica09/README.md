# Práctica 9. Construir una base de conocimiento técnica utilizando manuales, procedimientos, normas y especificaciones para responder consultas frecuentes del equipo de ingeniería mediante NotebookLM

**Duración de la práctica:** 30 minutos

## Descripción
Los participantes utilizarán **NotebookLM** para centralizar manuales, procedimientos, normas y especificaciones técnicas en una base de conocimiento estructurada, permitiendo realizar consultas especializadas, exportar respuestas rápidas y generar documentación para el equipo de ingeniería.

---

## Sección 1: Demostración del Instructor (3 Pasos)

1. **Creación del cuaderno técnico y carga de fuentes:**
   * El instructor ingresa a la plataforma **NotebookLM**, crea un nuevo cuaderno titulado "Base de Conocimiento de Ingeniería" y utiliza el chat para procesar la documentación mediante el siguiente prompt:
     ```text
     Actúa como un Administrador de Conocimiento Técnico.
     Procesa y organiza los documentos técnicos de la planta (manuales de equipos, procedimientos operativos y normas de seguridad) integrados como fuentes en este cuaderno, dejándolos listos para estructurar consultas y exportar referencias.
     ```

2. **Consulta estructurada sobre procedimientos y normas:**
   * El instructor utiliza la barra de chat de NotebookLM para realizar una consulta técnica avanzada mediante el siguiente prompt:
     ```text
     Actúa como un Ingeniero Consultor de Procesos.
     A partir de las fuentes cargadas en el cuaderno, extrae los requisitos normativos y los pasos críticos de mantenimiento para los equipos de bombeo de alta presión, generando un resumen estructurado listo para exportar.
     ```

3. **Generación de respuestas y notas ejecutivas:**
   * El instructor utiliza la función de notas y chat para consolidar la información obtenida y exportarla mediante el siguiente comando:
     ```text
     Actúa como un Especialista en Documentación Operativa.
     Sintetiza las respuestas obtenidas sobre las consultas frecuentes de ingeniería en un formato de notas ejecutivas con referencias cruzadas a las normas y manuales originales, listo para exportar.
     ```

---

## Sección 2: Práctica Guiada del Participante (5 Pasos)

1. **Creación y configuración del cuaderno técnico en NotebookLM:**
   * Ingresa a la interfaz de **NotebookLM**, crea un nuevo cuaderno especializado para tu área de ingeniería y prepara el espacio de trabajo digital para recibir fuentes.

2. **Carga de fuentes documentales mediante instrucción en el chat:**
   * Envía la siguiente directriz en el chat del cuaderno para incorporar la documentación base y dejarla lista para exportar:
     ```text
     Actúa como un Gestor de Información Técnica.
     Integra los manuales de equipos, especificaciones de materiales y procedimientos operativos normalizados proporcionados como fuentes de conocimiento del cuaderno, indexando su contenido y estructurándolo para su exportación.
     ```

3. **Consulta de procedimientos y resolución de dudas técnicas:**
   * Realiza una consulta específica sobre las directrices técnicas utilizando el siguiente prompt en el chat:
     ```text
     Actúa como un Ingeniero de Soporte Técnico.
     Consulta las fuentes del cuaderno y detalla los pasos correctos para la calibración de válvulas de control y los límites operativos permitidos según las normas técnicas cargadas, generando un formato claro para exportar.
     ```

4. **Extracción y exportación de respuestas frecuentes (FAQ):**
   * Pide al asistente que compile las preguntas recurrentes del equipo técnico mediante la siguiente instrucción:
     ```text
     Actúa como un Especialista en Estandarización Operativa.
     A partir de las interacciones previas, genera un documento de preguntas frecuentes (FAQ) estructurado con las respuestas exactas extraídas de las fuentes, dejándolo listo para exportar al equipo de ingeniería.
     ```

5. **Validación y auditoría de la base de conocimiento:**
   * Ejecuta una última verificación en el cuaderno enviando el siguiente prompt de control para asegurar la trazabilidad del contenido exportado:
     ```text
     Actúa como un Auditor de Calidad Técnica.
     Revisa que las respuestas generadas en la base de conocimiento incluyan las citas y referencias correctas a los manuales originales, asegurando la consistencia de la información lista para exportar.
     ```

## Resultado esperado
Una base de conocimiento técnica centralizada y funcional en **NotebookLM**, capaz de procesar manuales, normas y procedimientos para responder consultas especializadas y generar documentación lista para exportar y compartir con el equipo de ingeniería.
