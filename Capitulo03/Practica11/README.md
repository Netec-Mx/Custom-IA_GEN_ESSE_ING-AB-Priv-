# Práctica 11. Analizar una base de datos de producción, mantenimiento o calidad utilizando Advanced Data Analysis para identificar tendencias, anomalías y oportunidades de optimización, generando posteriormente un informe técnico en Canvas

**Duración de la práctica:** 30 minutos

## Descripción
> *Nota importante:* Como la interfaz de **Canvas** ya no está disponible en la plataforma actual de ChatGPT, esta práctica ha sido adaptada para utilizar el **panel lateral de edición y visualización de texto**, manteniendo exactamente el mismo flujo profesional de redacción, exportación y refinamiento de informes técnicos.

Los participantes utilizarán **Advanced Data Analysis** y su asistente autogenerado en ChatGPT para procesar bases de datos operativas de producción, mantenimiento o calidad mediante instrucciones detalladas en lenguaje natural (sin necesidad de manipular archivos externos, ya que el entorno genera los conjuntos de datos simulados de forma automatizada). El sistema analizará tendencias y anomalías estadísticas, estructurará los hallazgos y generará el informe técnico completo listo para exportar a GitHub.

---

## Sección 1: Demostración del Instructor (3 Pasos)

1. **Generación automática del entorno de datos y análisis estadístico inicial:**
   * El instructor ingresa al chat de ChatGPT y ejecuta un comando detallado para estructurar los datos y realizar el diagnóstico operativo:
     ```text
     Actúa como un Científico de Datos Industriales. Genera un conjunto de datos simulado y robusto de operaciones industriales que incluya registros detallados de producción por turno, tiempos de paro por fallas mecánicas y métricas de calidad. Utiliza Advanced Data Analysis para ejecutar un análisis estadístico automatizado, calcula las tasas de eficiencia global de los equipos (OEE), identifica las principales tendencias temporales y detecta anomalías estadísticas en las líneas con mayor impacto negativo, presentando los resultados en tablas y gráficos claros listos para exportar.
     ```

2. **Verificación visual y validación de anomalías críticas:**
   * El instructor revisa el comportamiento de las métricas generadas por el intérprete de código y solicita un desglose más profundo de los paros no planificados utilizando el siguiente prompt de refinamiento en el chat:
     ```text
     Actúa como un Ingeniero de Confiabilidad. Revisa el análisis previo y profundiza en las causas raíz de las anomalías detectadas en los tiempos de paro. Genera una categorización detallada de los fallos mecánicos más recurrentes y calcula su frecuencia acumulada para validar su criticidad en el proceso operativo.
     ```

3. **Estructuración y exportación del informe técnico en el editor de texto:**
   * El instructor traslada los hallazgos analíticos consolidados hacia el panel lateral de texto para redactar el documento formal mediante la siguiente instrucción guiada:
     ```text
     Actúa como un Documentador Técnico Senior. A partir de los resultados estadísticos y hallazgos de anomalías obtenidos, redacta un informe técnico formal y completo en el editor lateral que contenga: un Resumen Ejecutivo de la operación, el Diagnóstico detallado de Tendencias y Anomalías, y un Plan de Optimización Correctiva, utilizando un formato de Markdown limpio estructurado para su exportación directa a GitHub.
     ```

---

## Sección 2: Práctica Guiada del Participante (5 Pasos)

1. **Inicialización del entorno de simulación y carga de parámetros operativos:**
   * Abre tu interfaz de ChatGPT y mantén la vista en el panel principal de chat para preparar el espacio de trabajo digital mediante una instrucción inicial guiada:
     ```text
     Actúa como un Especialista en Operaciones y Manufactura. Configura el espacio de trabajo del chat para recibir un conjunto de datos simulado de alta fidelidad sobre rendimiento industrial, estableciendo los parámetros base para evaluar la eficiencia de las líneas de producción, los costos de mantenimiento correctivo y los índices de rechazo por calidad.
     ```

2. **Ejecución del análisis integral de tendencias y detección de anomalías:**
   * Copia y envía la siguiente instrucción detallada dentro del chat para que la herramienta procese los datos y calcule los indicadores clave:
     ```text
     Actúa como un Analista Senior de Operaciones. Genera un set de datos de prueba con registros completos de producción y mantenimiento, y utiliza Advanced Data Analysis para procesar la información, calcular los indicadores clave de desempeño (KPIs) de la planta, aislar las anomalías críticas en las líneas de ensamble y generar visualizaciones gráficas con un resumen estructurado listo para exportar.
     ```

3. **Auditoría y filtrado de los principales puntos de fallo operativo:**
   * Verifica los cálculos estadísticos generados por el intérprete de código en la interfaz y solicita un desglose ejecutivo de los hallazgos con el siguiente comando en el chat:
     ```text
     Filtra las 3 principales anomalías operativas detectadas en los datos analizados, detalla sus frecuencias de ocurrencia, calcula el impacto económico estimado en los costos de producción y prepara la información estructurada para integrarla en el informe técnico formal.
     ```

4. **Redacción del informe técnico estructurado en el editor de texto integrado:**
   * Envía la siguiente directriz para que el sistema redacte el documento técnico completo utilizando el panel lateral de edición y visualización de texto:
     ```text
     Actúa como un Gerente de Ingeniería Industrial. A partir de todos los hallazgos y métricas procesadas, redacta un informe técnico formal en el editor lateral de texto que contenga: Introducción y Objetivos del Análisis, Diagnóstico de Tendencias y Anomalías Operativas, y un Plan de Acción Correctivo, asegurando un tono profesional y técnico.
     ```

5. **Refinamiento final de formato Markdown y preparación para GitHub:**
   * Envía el último prompt en el chat para optimizar la presentación visual del documento y dejarlo listo para su publicación:
     ```text
     Revisa el tono técnico del informe generado en el editor, asegura que todo el formato utilice etiquetas de Markdown limpias y estructuradas (con títulos, subtítulos, listas y bloques bien definidos), y déjalo completamente listo para copiar y pegar directamente en un repositorio de GitHub.
     ```

## Resultado esperado
Un análisis completo de datos operativos generado y procesado de forma automatizada mediante **Advanced Data Analysis**, complementado con un informe técnico estructurado en el editor de texto y listo para exportar a GitHub, facilitando la toma de decisiones basada en evidencia estadística sin necesidad de manipular archivos externos.
